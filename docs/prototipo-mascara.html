    Como decidir

    1. Pegue só os bits azuis, os de rede, dos dois IPs.
    2. Se forem todos iguais, é a mesma rede: conversam direto, pelo switch.
    3. Se um único bit azul for diferente, são redes diferentes: precisam do roteador (gateway).
    4. Teste: deixe os mesmos IPs e mude o "/". A resposta muda!

    O truque do salto

    1. Ache o bloco do IP onde a máscara deixa de ser 255.
    2. Salto = 256 − valor da máscara nesse bloco. Ex.: /26 → máscara .192 → salto 64.
    3. As redes andam de salto em salto: 0, 64, 128, 192.
    4. Rede = o múltiplo do salto logo abaixo do IP. Broadcast = próxima rede − 1.
    5. Hosts = 2n − 2, n = 32 − o número do "/".

    Respostas aceitas: o endereço completo (192.168.10.64) ou só um número quando a pergunta pedir.
